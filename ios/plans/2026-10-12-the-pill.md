# The Pill on iPhone (IOS-010) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The signature on the phone. One drawing module paints the pill everywhere it appears, following DESIGN.md's stage table, in the two free styles (bars and speckle), live from the voice.

**Architecture:**
- `ios/Shared/Pill.swift` is a pure painter: a `PillFrame` (style, stage, recent levels, seconds into the stage, still or not) draws into any CGContext. So previews, tests, the capture script, the keyboard, and the app all draw the same pill, and tests can count its paint pixel by pixel.
- `ios/Shared/PillView.swift` is the one view. It keeps the last moments of loudness and runs a 30 fps display link only while its stage moves. The keyboard's pad holds it inside the pill's capsule; the app wraps the same view for SwiftUI.
- The keyboard never hears audio. While a keyboard take records, the app writes the loudness to an 8-byte file in the app group about 30 times a second, and the keyboard reads only that.
- The chosen style lives beside the session's state in the app group (`pill.json`).
- A light haptic marks a take's start and stop.
- `npm run ios:pill-shots` saves every stage of both styles as images, like desktop's ink shots.

**Tech Stack:** Swift 6, CoreGraphics, UIKit (CADisplayLink, UIImpactFeedbackGenerator), SwiftUI (UIViewRepresentable, sensoryFeedback), Swift Testing, vitest.

**Spec:** `ios/prd.json` IOS-010, with `conventions` (design, verify, docs). Also `DESIGN.md`: the Motion verbs, and The ink waveforms' stage table. Also `CLAUDE.md`. It builds on IOS-008 (the pad, the mailbox, the bridge) and IOS-009 (the screen murmur opens to). Desktop's `src/renderer/overlay/Bars.tsx`, `SpeckleWave.tsx`, and `sheen.ts` are murmur's own code, and the iPhone draws the same ideas. The design skills were consulted: frontend-design, elite-saas-designer, and ui-skills-root.

```swift
// SPDX-License-Identifier: GPL-3.0-only
// The pill (ios/prd.json IOS-010): one drawing for everywhere it appears,
// the keyboard, the screen murmur opens to, first-run practice, and later
// the Look grid. It follows DESIGN.md's stage table. Idle is small, dry,
// and still, and never amber, even while a session keeps the microphone
// warm. Recording is wet amber at the voice's level, cooling to brand gold
// as it ages. Processing cools with one sheen, then a softer sheen every 2
// seconds. Inserted sinks flat; no speech is a dry grey scrape; an error is
// plain red. Every frame is a pure function of its inputs, so previews,
// tests, and the capture script all see the same pill.
import CoreGraphics
import Foundation
import UIKit

enum PillStage: Equatable, Sendable {
    case idle, recording, processing, inserted, noSpeech, error
}

/// The free styles; the other five arrive with belts (IOS-020).
enum PillStyle: String, CaseIterable, Codable, Sendable {
    case bars, speckle
}

/// One frame of the pill.
struct PillFrame {
    var style: PillStyle
    var stage: PillStage
    /// Recent loudness, oldest first, 0 to 1.
    var levels: [Float]
    /// Seconds since the stage began.
    var time: TimeInterval
    /// Reduce Motion: each stage as a still frame.
    var still: Bool
}

enum Pill {
    static let barCount = 21
    /// How long wet paint takes to dry to gold, and the pill to sink flat.
    static let dry: TimeInterval = 0.6
    static let sink: TimeInterval = 0.35

    /// What VoiceOver reads for the pill in each stage.
    static func label(_ stage: PillStage) -> String {
        switch stage {
        case .idle: "Start dictation"
        case .recording: "Recording"
        case .processing: "Working"
        case .inserted: "Words added"
        case .noSpeech: "Heard nothing"
        case .error: "Failed, retry in murmur"
        }
    }

    /// Whether the stage changes from frame to frame, so the view redraws
    /// only while it does.
    static func moves(_ stage: PillStage, at time: TimeInterval, still: Bool) -> Bool {
        guard !still else { return false }
        switch stage {
        case .recording: return true
        case .processing: return time < Sheen.limit + 1
        case .inserted: return time < sink
        case .idle, .noSpeech, .error: return false
        }
    }

    // MARK: Paint

    static func paint(_ frame: PillFrame, in rect: CGRect, context: CGContext) {
        guard rect.width > 0, rect.height > 0 else { return }
        context.saveGState()
        defer { context.restoreGState() }
        switch frame.style {
        case .bars: paintBars(frame, in: rect, context: context)
        case .speckle: paintSpeckle(frame, in: rect, context: context)
        }
    }

    /// The levels a still pill shows: a steady voice's shape.
    static let stillLevels: [Float] = (0..<barCount).map { 0.25 + 0.45 * Float(abs(sin(Double($0) * 0.55))) }

    /// The last barCount levels, oldest first, padded with silence.
    static func recent(_ levels: [Float]) -> [Float] {
        let tail = levels.suffix(barCount).map { min(1, max(0, $0)) }
        return Array(repeating: 0, count: barCount - tail.count) + tail
    }

    private static func paintBars(_ frame: PillFrame, in rect: CGRect, context: CGContext) {
        let n = barCount
        let width = rect.width / (CGFloat(n) + 0.7 * CGFloat(n - 1))
        let gap = width * 0.7
        let low = max(width, rect.height * 0.12)
        let high = rect.height * 0.9
        // A still pill never gathers levels, so it shows a steady voice's
        // finished shape: never a blank space.
        let levels = frame.still ? stillLevels : recent(frame.levels)
        let dried = frame.still ? 1 : ease(frame.time / dry)
        let sunk = frame.still ? 1 : ease(frame.time / sink)
        let sheen = frame.stage == .processing && !frame.still ? Sheen.at(frame.time) : nil
        var scrape = Seeded(7)
        for i in 0..<n {
            let age = CGFloat(n - 1 - i) / CGFloat(n - 1)
            let level = CGFloat(levels[i])
            let height: CGFloat
            let color: RGBA
            switch frame.stage {
            case .idle:
                height = low
                color = RGBA.cream22
            case .recording:
                height = low + level * (high - low)
                color = RGBA.amber.mix(RGBA.brand, age * 0.7)
            case .processing:
                height = low + level * (high - low)
                color = RGBA.amber.mix(RGBA.brand, age * 0.7).mix(RGBA.brand, dried)
            case .inserted:
                height = low + level * (high - low) * (1 - sunk)
                color = RGBA.brand.mix(RGBA.cream22, sunk)
            case .noSpeech:
                height = low * (0.7 + 0.6 * scrape.next())
                color = RGBA.grey
            case .error:
                height = low
                color = RGBA.red
            }
            let x = rect.minX + CGFloat(i) * (width + gap)
            let bar = CGRect(x: x, y: rect.midY - height / 2, width: width, height: height)
            let path = CGPath(roundedRect: bar, cornerWidth: width / 2, cornerHeight: min(width / 2, height / 2), transform: nil)
            context.setFillColor(color.cgColor)
            context.addPath(path)
            context.fillPath()
            if let sheen {
                let glow = sheen.alpha * gauss((x + width / 2 - rect.minX) / rect.width - sheen.center)
                if glow > 0.01 {
                    context.setFillColor(RGBA.text.with(alpha: glow).cgColor)
                    context.addPath(path)
                    context.fillPath()
                }
            }
        }
    }

    /// The speckle field: 84 dots on a jittered grid, the same dots every
    /// time, a few of them warm sparks that show amber only while live.
    private static let dots: [Dot] = {
        var random = Seeded(31)
        let cols = 14
        let rows = 6
        return (0..<(cols * rows)).map { i in
            Dot(
                x: (CGFloat(i % cols) + 0.2 + 0.6 * random.next()) / CGFloat(cols),
                y: (CGFloat(i / cols) + 0.2 + 0.6 * random.next()) / CGFloat(rows),
                radius: 0.5 + 0.9 * random.next(),
                phase: random.next() * .pi * 2,
                speed: 0.4 + 1.1 * random.next(),
                alpha: 0.16 + 0.42 * random.next(),
                warm: random.next() < 0.16
            )
        }
    }()

    private struct Dot {
        let x, y, radius, phase, speed, alpha: CGFloat
        let warm: Bool
    }

    private static func paintSpeckle(_ frame: PillFrame, in rect: CGRect, context: CGContext) {
        // The phone's pill is smaller than desktop's, so the dust is a touch
        // larger for its size, and the warm sparks carry their full color.
        let scale = rect.height / 24
        let t = CGFloat(frame.time)
        let level = frame.still ? 0.5 : CGFloat(recent(frame.levels).last ?? 0)
        let energy = min(1, level * 1.1)
        let dried = frame.still ? 1 : ease(frame.time / dry)
        let sunk = frame.still ? 1 : ease(frame.time / sink)
        let sheen = frame.stage == .processing && !frame.still ? Sheen.at(frame.time) : nil
        for dot in dots {
            var x = rect.minX + dot.x * rect.width
            var y = rect.minY + dot.y * rect.height
            var radius = dot.radius * scale
            var alpha = dot.alpha
            var color = RGBA.text
            switch frame.stage {
            case .idle:
                alpha *= 0.45
            case .recording:
                let jitter = frame.still ? 0 : (1 + energy * 4) * scale
                x += sin(t / 0.19 * dot.speed + dot.phase) * jitter
                y += cos(t / 0.16 * dot.speed + dot.phase * 1.7) * jitter
                radius *= 1 + energy * 0.8
                if dot.warm {
                    color = RGBA.amber
                    alpha = 0.55 + 0.45 * energy
                } else {
                    alpha *= 0.4 + energy * 0.6
                }
            case .processing:
                if dot.warm {
                    color = RGBA.amber.mix(RGBA.brand, dried)
                    alpha = 0.7
                } else {
                    alpha *= 0.55
                }
            case .inserted:
                y += (rect.midY - y) * sunk
                alpha *= 0.55 * (1 - 0.5 * sunk)
                color = RGBA.brand.mix(RGBA.text, sunk)
            case .noSpeech:
                y = rect.midY + (y - rect.midY) * 0.15
                alpha *= 0.6
                color = RGBA.grey
            case .error:
                alpha = 0.5 + alpha * 0.5
                color = RGBA.red
            }
            alpha *= fade(x - rect.minX, rect.width, edge: 7 * scale) * fade(y - rect.minY, rect.height, edge: 8 * scale)
            if let sheen {
                alpha = min(1, alpha + sheen.alpha * gauss((x - rect.minX) / rect.width - sheen.center))
            }
            guard alpha > 0.005 else { continue }
            context.setFillColor(color.with(alpha: color.a * alpha).cgColor)
            context.fillEllipse(in: CGRect(x: x - radius, y: y - radius, width: radius * 2, height: radius * 2))
        }
    }

    // MARK: Helpers

    /// Ease out, clamped to 0 through 1.
    static func ease(_ progress: TimeInterval) -> CGFloat {
        let p = CGFloat(min(1, max(0, progress)))
        return 1 - (1 - p) * (1 - p) * (1 - p)
    }

    /// A soft band around 0, about a tenth of the pill wide.
    private static func gauss(_ distance: CGFloat) -> CGFloat {
        exp(-(distance / 0.12) * (distance / 0.12))
    }

    /// Fades toward both ends of a span, so a field melts into the pill.
    private static func fade(_ position: CGFloat, _ span: CGFloat, edge: CGFloat) -> CGFloat {
        let f = min(1, max(0, min(position, span - position) / edge))
        return f * f * (3 - 2 * f)
    }
}

/// The drying sheen, as on desktop (src/renderer/overlay/sheen.ts): one pass
/// as the paint dries, then a softer one every 2 seconds until the words
/// land, so a slow provider never looks frozen. None after 2 minutes.
enum Sheen {
    static let every: TimeInterval = 2
    static let limit: TimeInterval = 120

    /// Where the sheen is t seconds into processing, as a fraction of the
    /// pill's width, and how bright; nil between passes.
    static func at(_ t: TimeInterval) -> (center: CGFloat, alpha: CGFloat)? {
        guard t >= 0 else { return nil }
        let first = pass(t)
        if first < 1.4 { return (first, 0.4) }
        guard t >= every, t - t.truncatingRemainder(dividingBy: every) < limit else { return nil }
        let again = pass(t.truncatingRemainder(dividingBy: every))
        return again < 1.4 ? (again, 0.22) : nil
    }

    private static func pass(_ u: TimeInterval) -> CGFloat {
        CGFloat((u / 0.7 - 0.2) * 1.5)
    }
}

/// A color as components, for mixing paint.
struct RGBA: Equatable {
    var r, g, b, a: CGFloat

    init(r: CGFloat, g: CGFloat, b: CGFloat, a: CGFloat = 1) {
        (self.r, self.g, self.b, self.a) = (r, g, b, a)
    }

    init(_ color: UIColor) {
        var (r, g, b, a): (CGFloat, CGFloat, CGFloat, CGFloat) = (0, 0, 0, 0)
        color.getRed(&r, green: &g, blue: &b, alpha: &a)
```

```swift
// The pill as a view (ios/prd.json IOS-010), for the keyboard's pad and,
// wrapped, for the app's screens. It keeps the last moments of loudness and
// redraws about 30 times a second only while its stage moves; at rest it
// draws once and the display link stops.
import UIKit

final class PillView: UIView {
    var style: PillStyle = .bars {
        didSet { if style != oldValue { setNeedsDisplay() } }
    }

    /// Reads how loud the take is now, 0 to 1, while recording.
    var level: (@MainActor () -> Float)?

    private(set) var stage: PillStage = .idle
    private var levels = [Float](repeating: 0, count: Pill.barCount)
    private var smoothed: Float = 0
    private var began = CACurrentMediaTime()
    private var link: CADisplayLink?
    private var still = UIAccessibility.isReduceMotionEnabled

    override init(frame: CGRect) {
        super.init(frame: frame)
        isOpaque = false
        backgroundColor = .clear
        contentMode = .redraw
        isUserInteractionEnabled = false
        isAccessibilityElement = false
        NotificationCenter.default.addObserver(self, selector: #selector(motionChanged), name: UIAccessibility.reduceMotionStatusDidChangeNotification, object: nil)
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) { fatalError("PillView is built in code") }

    /// Shows a stage from now. A new recording starts from silence; the
    /// stages after it keep the take's last shape, so it dries and sinks
    /// where it was.
    func show(_ stage: PillStage) {
        guard stage != self.stage else { return }
        if stage == .recording {
            levels = [Float](repeating: 0, count: Pill.barCount)
            smoothed = 0
        }
        self.stage = stage
        began = CACurrentMediaTime()
        setNeedsDisplay()
        run()
    }

    override func draw(_ rect: CGRect) {
        guard let context = UIGraphicsGetCurrentContext() else { return }
        Pill.paint(current, in: bounds, context: context)
    }

    /// The frame drawn now.
    var current: PillFrame {
        PillFrame(style: style, stage: stage, levels: levels, time: CACurrentMediaTime() - began, still: still)
    }

    override func didMoveToWindow() {
        super.didMoveToWindow()
        run()
    }

    /// Runs the display link while the stage moves and the view is on screen.
    private func run() {
        let moving = window != nil && Pill.moves(stage, at: CACurrentMediaTime() - began, still: still)
        if moving, link == nil {
            let link = CADisplayLink(target: Tick(self), selector: #selector(Tick.fire(_:)))
            link.preferredFrameRateRange = CAFrameRateRange(minimum: 20, maximum: 30, preferred: 30)
            link.add(to: .main, forMode: .common)
            self.link = link
        } else if !moving {
            link?.invalidate()
            link = nil
        }
    }

    fileprivate func tick() {
        if stage == .recording, let level {
            smoothed += (level() - smoothed) * 0.35
            levels.removeFirst()
            levels.append(smoothed)
        }
        setNeedsDisplay()
        run()
    }

    @objc private func motionChanged() {
        still = UIAccessibility.isReduceMotionEnabled
        setNeedsDisplay()
        run()
    }
}

/// The display link's target, holding the view weakly so the link never
/// keeps it alive; once the view is gone, the link stops itself.
@MainActor private final class Tick: NSObject {
    weak var view: PillView?

    init(_ view: PillView) {
        self.view = view
    }

    @objc func fire(_ link: CADisplayLink) {
        guard let view else {
            link.invalidate()
            return
        }
        view.tick()
    }
}

extension PillStage {
    /// The pill's stage for a keyboard take, from the mailbox.
    init(_ phase: MailboxEntry.Phase?) {
        switch phase {
        case .listening?: self = .recording
        case .working?: self = .processing
        case .ready?: self = .inserted
        case .nothing?: self = .noSpeech
        case .failed?: self = .error
        case nil: self = .idle
        }
    }
}

/// How loud the take is now, which the app writes about 30 times a second
/// while a keyboard take records, for the keyboard's pill: 8 bytes, the
/// level and a count. The keyboard reads nothing else about the audio.
struct LevelFile: Sendable {
    let url: URL?

    static let shared = LevelFile(url: AppGroup.containerURL?.appending(path: "level"))

    func write(_ level: Float, count: UInt32) {
        guard let url else { return }
        var bytes = Data()
        withUnsafeBytes(of: level.bitPattern.littleEndian) { bytes.append(contentsOf: $0) }
        withUnsafeBytes(of: count.littleEndian) { bytes.append(contentsOf: $0) }
        try? bytes.write(to: url, options: .completeFileProtectionUntilFirstUserAuthentication)
    }

    /// The level and its count, or nil when there is none.
    func read() -> (level: Float, count: UInt32)? {
        guard let url, let data = try? Data(contentsOf: url), data.count == 8 else { return nil }
        let bits = data.prefix(4).enumerated().reduce(UInt32(0)) { $0 | UInt32($1.element) << (8 * UInt32($1.offset)) }
        let count = data.suffix(4).enumerated().reduce(UInt32(0)) { $0 | UInt32($1.element) << (8 * UInt32($1.offset)) }
        return (Float(bitPattern: bits), count)
    }
}
```

```swift
// SPDX-License-Identifier: GPL-3.0-only
// The app's side of the keyboard (ios/prd.json IOS-008): it hears the
// keyboard's start, stop, and cancel, runs the take on the app's one take
// model under the id the keyboard asked with, and tells the keyboard how
// it goes through the mailbox. Only a take the keyboard started goes to
// the mailbox, so a take made on the Dictate screen never turns up in
// another app. While a keyboard take records, its loudness goes to the
// level file for the keyboard's pill (IOS-010).
import Foundation
import Observation

@MainActor final class KeyboardBridge {
    /// How long a keyboard's ask stays good. One that waited longer, sent
    /// while murmur was not running, is dropped.
    static let askLife: TimeInterval = 3
    /// How long a keyboard's ask stays good for a take link: opening murmur
    /// from cold can take a while.
    static let linkLife: TimeInterval = 60
    /// The longest a keyboard take may record. One nobody stopped (you
    /// walked away from it) ends here and is dropped, never sent.
    static let takeLimit: TimeInterval = 10 * 60

    private let model: TakeModel
    private let mailbox: Mailbox
    private let announce: @MainActor (Signal) -> Void
    private let limit: TimeInterval
    private let levels: LevelFile
    private var listener: SignalListener?
    /// The take the keyboard asked for, until it ends.
    private var take: UUID?
    /// A cancel heard while the take was still starting.
    private var cancelled = false
    private var startedAt = Date.distantPast

    init(
        model: TakeModel, mailbox: Mailbox, limit: TimeInterval = KeyboardBridge.takeLimit, levels: LevelFile = .shared,
        announce: @escaping @MainActor (Signal) -> Void = { $0.post() }
    ) {
        self.model = model
        self.mailbox = mailbox
        self.limit = limit
        self.levels = levels
        self.announce = announce
    }

    /// Hears the keyboard from now on and follows the take model.
    func listen() {
        listener = SignalListener([.start, .stop, .cancel]) { [weak self] signal in
            self?.hear(signal)
        }
        follow()
    }

    func hear(_ signal: Signal) {
        switch signal {
        case .start:
            guard let id = mailbox.answer(within: Self.askLife) else { return }
            begin(id)
        case .stop:
            guard take != nil, model.isRecording else { return }
            Task { await model.stop() }
        case .cancel:
            guard take != nil else { return }
            if model.isRecording { model.cancel() } else { cancelled = true }
        case .changed, .busy, .end:
            break
        }
    }

    /// The keyboard opened murmur with a take link (IOS-009). True when the
    /// take began, so murmur shows Recording only for a take that is there.
    /// Only the keyboard's own ask, left in the mailbox before it opened
    /// murmur, lets a link start a take: a link from anywhere else starts
    /// nothing. The ask is used up here, so it never starts a second take.
    @discardableResult
    func opened(_ id: UUID) -> Bool {
        let asked = mailbox.answer(within: Self.linkLife)
        // A start murmur answered late and the link for the same take are one
        // take, and a cancel heard on the way does not drop it.
        if take == id {
            cancelled = false
            return true
        }
        guard asked == id else { return false }
        return begin(id)
    }

    @discardableResult
    private func begin(_ id: UUID) -> Bool {
        guard take == nil, !model.isRecording, !model.isBusy else {
            announce(.busy)
            return false
        }
        take = id
        startedAt = .now
        cancelled = false
        // Written here, not read from the model, whose state may still
        // be the last take's words.
        write(.listening)
        Task { await settle(id) }
        return true
    }

    /// Settles how the start went. A start that did not record ends failed
    /// here: the model's state may not change at all (denied twice), and
    /// following it alone would leave the take open forever.
    private func settle(_ id: UUID) async {
        await model.start()
        guard take == id else { return }
        if cancelled {
            model.cancel()
            write(.nothing, ends: true)
        } else if !model.isRecording {
            write(.failed, ends: true)
        } else {
            Task { await limit(id) }
            Task { await stream(id) }
        }
    }

    /// Writes the take's loudness for the keyboard's pill about 30 times a
    /// second while it records, then silence.
    private func stream(_ id: UUID) async {
        var count: UInt32 = 0
        while take == id, model.isRecording {
            count &+= 1
            levels.write(model.level, count: count)
            try? await Task.sleep(for: .milliseconds(33))
        }
        levels.write(0, count: count &+ 1)
    }

    /// Ends a take still recording at the limit, dropping what it heard.
    private func limit(_ id: UUID) async {
        try? await Task.sleep(for: .seconds(limit))
        guard take == id, model.isRecording else { return }
        model.cancel()
    }

    /// Publishes each change of the take model's state, for as long as the
    /// bridge lives.
    private func follow() {
        withObservationTracking {
            _ = model.state
        } onChange: { [weak self] in
            Task { @MainActor in
                self?.publish()
                self?.follow()
            }
        }
    }

    private func publish() {
        guard take != nil else { return }
        switch model.state {
        case .recording: write(.listening)
        case .transcribing: write(.working)
        case .words(let text): write(.ready, words: text, ends: true)
        case .heardNothing: write(.nothing, ends: true)
        case .failed, .micOff, .micFailed: write(.failed, ends: true)
        // Idle again after the take began: it was cancelled.
        case .idle: write(.nothing, ends: true)
        }
    }

    private func write(_ phase: MailboxEntry.Phase, words: String? = nil, ends: Bool = false) {
        guard let take else { return }
        mailbox.write(MailboxEntry(take: take, phase: phase, words: words, at: startedAt))
        announce(.changed)
        if ends { self.take = nil }
    }
}

extension KeyboardBridge {
    private static var shared: KeyboardBridge?

    /// The one bridge for the app's life, on the app's take model, started
    /// by whichever comes first: the app's first screen or a take link.
    static func live() -> KeyboardBridge? {
        if let shared { return shared }
        guard let model = TakeModel.live(), let mailbox = Mailbox.shared else { return nil }
        let bridge = KeyboardBridge(model: model, mailbox: mailbox)
        bridge.listen()
        shared = bridge
        return bridge
    }
}
```

```swift
// SPDX-License-Identifier: GPL-3.0-only
// The murmur keyboard, a dictation pad (ios/prd.json IOS-008, IOS-009):
// tap the pill to start a take and again to stop it. With no session
// running, the first tap opens murmur, which starts one already
// listening; you swipe back and keep talking. During a session a tap
// starts a take without leaving your app. The keyboard only asks the app
// for a take under its own id, signals it (start, stop, cancel, end), and
// reads the mailbox; it never touches the microphone or the network.
// Words land at the cursor once, or wait as Insert last when you left the
// field before they arrived. The pill is drawn from the take's stage and
// the loudness the app writes to the app group (IOS-010), with a light tap
// when a take starts and when it stops.
import UIKit

final class KeyboardViewController: UIInputViewController {
    private let pad = PadView()
    private let memory = UserDefaults.standard
    private var listener: SignalListener?
    /// The take this keyboard is waiting on, kept across keyboards.
    private var waiting: Pad.Waiting? {
        didSet { Pad.Waiting.save(waiting, to: memory) }
    }
    /// The phase of that take, as the mailbox last said.
    private var phase: MailboxEntry.Phase?
    private var visible = false
    private var deleteRepeat: Timer?
    private var noAnswer: Timer?
    /// Brings the pill back to rest after it shows how a take ended.
    private var rest: Timer?
    private let haptic = UIImpactFeedbackGenerator(style: .light)

    override func viewDidLoad() {
        super.viewDidLoad()
        pad.translatesAutoresizingMaskIntoConstraints = false
        view.addSubview(pad)
        let height = view.heightAnchor.constraint(equalToConstant: 236)
        height.priority = .defaultHigh
        NSLayoutConstraint.activate([
            height,
            pad.leadingAnchor.constraint(equalTo: view.leadingAnchor),
            pad.trailingAnchor.constraint(equalTo: view.trailingAnchor),
            pad.topAnchor.constraint(equalTo: view.topAnchor),
            pad.bottomAnchor.constraint(equalTo: view.bottomAnchor)
        ])
        pad.globe.addTarget(self, action: #selector(handleInputModeList(from:with:)), for: .allTouchEvents)
        pad.pill.addTarget(self, action: #selector(tapPill), for: .touchUpInside)
        pad.space.addTarget(self, action: #selector(tapSpace), for: .touchUpInside)
        pad.returnKey.addTarget(self, action: #selector(tapReturn), for: .touchUpInside)
        pad.insertLast.addTarget(self, action: #selector(tapInsertLast), for: .touchUpInside)
        pad.delete.addTarget(self, action: #selector(deleteDown), for: .touchDown)
        pad.delete.addTarget(self, action: #selector(deleteUp), for: [.touchUpInside, .touchUpOutside, .touchCancel])
        pad.pill.addTarget(self, action: #selector(pillDown), for: .touchDown)
        pad.wave.level = { LevelFile.shared.read()?.level ?? 0 }
        pad.status.text = Pad.idleHint
        listener = SignalListener([.changed, .busy]) { [weak self] signal in
            signal == .busy ? self?.heardBusy() : self?.refresh()
        }
    }

    override func viewWillAppear(_ animated: Bool) {
        super.viewWillAppear(animated)
        visible = true
        pad.setFullAccess(hasFullAccess)
        pad.wave.style = PillLook.read().style
        waiting = Pad.Waiting.load(from: memory)
        // A take that opened murmur is taken over by the keyboard you come
        // back to, and lands in its field.
        if var opened = waiting, opened.opened, !opened.adopted {
            opened.adopt(textDocumentProxy.documentIdentifier)
            waiting = opened
        }
        refresh()
        // Back from murmur, its take should be in the mailbox by now.
        if waiting?.opened == true, phase == nil { expectAnswer(within: 3, else: Pad.noAnswer) }
    }

    override func viewWillDisappear(_ animated: Bool) {
        super.viewWillDisappear(animated)
        visible = false
        // A take still starting or listening when the keyboard goes away is
        // dropped; one being transcribed comes back as Insert last. A take
        // that opened murmur goes on while you go there, and is dropped like
        // any other once a keyboard has taken it over.
        if let waiting, waiting.cancelsOnLeave(phase: phase) {
            Signal.cancel.post()
            end(nil)
        }
        noAnswer?.invalidate()
        deleteUp()
    }

    override func viewWillLayoutSubviews() {
        super.viewWillLayoutSubviews()
        pad.globe.isHidden = !needsInputModeSwitchKey
        setReturnTitle()
    }

    override func textDidChange(_ textInput: (any UITextInput)?) {
        super.textDidChange(textInput)
        setReturnTitle()
    }

    @objc private func pillDown() {
        haptic.prepare()
    }

    @objc private func tapPill() {
        switch (waiting, phase) {
        case (.some, .listening?):
            haptic.impactOccurred()
            Signal.stop.post()
            // The app moves on to working within a moment; when it does not,
            // it is no longer there.
            expectAnswer(within: 4, else: Pad.stoppedAnswering)
        case (.some, _):
            // This keyboard's take is still starting or being transcribed.
            break
        case (nil, _):
            let take = UUID()
            guard let mailbox = Mailbox.shared else { return }
            haptic.impactOccurred()
            rest?.invalidate()
            mailbox.ask(take)
            pad.insertLast.isHidden = true
            phase = nil
            if SessionState.read().isOn() {
                waiting = Pad.Waiting(take: take, opened: false, field: textDocumentProxy.documentIdentifier, at: .now)
                pad.status.text = "Starting"
                Signal.start.post()
                // A running session answers within a moment; when it does not,
                // murmur was closed, so open it with the same take. A late
                // answer to the start and the link are one take.
                expectAnswer(within: 2) { [weak self] in
                    self?.openMurmur(take)
                }
            } else {
                openMurmur(take)
            }
        }
    }

    /// Opens murmur with the take's link; murmur starts the session and the
    /// take, and you swipe back.
    private func openMurmur(_ take: UUID) {
        Mailbox.shared?.ask(take)
        guard let url = TakeLink.url(for: take), let scene = view.window?.windowScene else {
            end(Pad.openRefused)
            return
        }
        waiting = Pad.Waiting(take: take, opened: true, field: nil, at: .now)
        pad.status.text = Pad.opening
        scene.open(url, options: nil) { [weak self] opened in
            MainActor.assumeIsolated {
                if !opened, self?.waiting?.take == take { self?.end(Pad.openRefused) }
            }
        }
    }

    /// Ends the take with a line when the mailbox has not moved on in time.
    private func expectAnswer(within seconds: TimeInterval, else line: String) {
        expectAnswer(within: seconds) { [weak self] in
            Signal.cancel.post()
            self?.end(line)
        }
    }

    private func expectAnswer(within seconds: TimeInterval, otherwise: @escaping @MainActor () -> Void) {
        let waitingOn = phase
        noAnswer?.invalidate()
        noAnswer = Timer.scheduledTimer(withTimeInterval: seconds, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self, self.visible, self.waiting != nil, self.phase == waitingOn else { return }
                otherwise()
            }
        }
    }

    private func heardBusy() {
        guard waiting != nil, phase == nil else { return }
        noAnswer?.invalidate()
        end(Pad.busy)
    }

    @objc private func tapInsertLast() {
        if let words = Mailbox.shared?.claim() { insert(words) }
        pad.insertLast.isHidden = true
    }

    @objc private func tapSpace() { textDocumentProxy.insertText(" ") }
    @objc private func tapReturn() { textDocumentProxy.insertText("\n") }

    /// Delete repeats while held, after a short pause.
    @objc private func deleteDown() {
        textDocumentProxy.deleteBackward()
        deleteRepeat?.invalidate()
        deleteRepeat = Timer.scheduledTimer(withTimeInterval: 0.45, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated {
                self?.deleteRepeat = Timer.scheduledTimer(withTimeInterval: 0.08, repeats: true) { [weak self] _ in
                    MainActor.assumeIsolated { self?.textDocumentProxy.deleteBackward() }
                }
            }
        }
    }

    @objc private func deleteUp() {
        deleteRepeat?.invalidate()
        deleteRepeat = nil
    }

    private func setReturnTitle() {
        let title = Pad.returnTitle(textDocumentProxy.returnKeyType ?? .default)
        guard pad.returnKey.configuration?.title != title else { return }
        var look = pad.returnKey.configuration
        look?.title = title
        pad.returnKey.configuration = look
        pad.returnKey.accessibilityLabel = title
    }

    /// A long press on the pill holds End session while one runs.
    private func setSessionMenu() {
        guard SessionState.read().isOn() else {
            pad.pill.menu = nil
            return
        }
        pad.pill.menu = UIMenu(children: [
            UIAction(title: "End session", image: UIImage(systemName: "stop.circle")) { _ in Signal.end.post() }
        ])
    }

    /// Reads the mailbox and does what the newest entry asks, only while
    /// this keyboard is on screen.
    private func refresh() {
        guard visible, hasFullAccess, let mailbox = Mailbox.shared else { return }
        setSessionMenu()
        let entry = mailbox.read()
        if let entry, entry.take == waiting?.take, entry.phase != phase {
            phase = entry.phase
            noAnswer?.invalidate()
            // Transcribing and polish can take a while, but not forever.
            if phase == .working { expectAnswer(within: 90, else: Pad.stoppedAnswering) }
        }
        if waiting != nil { pad.setStage(PillStage(phase)) }
        let sameField = waiting?.sameField(as: textDocumentProxy.documentIdentifier) ?? false
        switch Pad.react(to: entry, mine: waiting?.take, sameField: sameField, visible: visible) {
        case .insert(let take):
            if let words = mailbox.claim(take) { insert(words) }
            end(nil, showing: .inserted)
        case .offerInsertLast:
            pad.insertLast.isHidden = false
            if entry?.take == waiting?.take { end(nil) }
        case .status(let line):
            pad.status.text = line
            if phase == .nothing { end(line, showing: .noSpeech) }
            if phase == .failed { end(line, showing: .error) }
        case .none:
            break
        }
    }

    private func insert(_ words: String) {
        textDocumentProxy.insertText(Pad.spaced(words, after: textDocumentProxy.documentContextBeforeInput))
    }

    /// Ends the take: the pill shows how it ended for a moment, then rests.
    private func end(_ line: String?, showing stage: PillStage = .idle) {
        waiting = nil
        phase = nil
        noAnswer?.invalidate()
        pad.setStage(stage)
        pad.status.text = line ?? Pad.idleHint
        rest?.invalidate()
        guard stage != .idle else { return }
        rest = Timer.scheduledTimer(withTimeInterval: 2.5, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self, self.waiting == nil else { return }
                self.pad.setStage(.idle)
            }
        }
    }
}
```

```swift
    /// The pill's stage for a take in the app.
    init(_ state: TakeModel.State) {
        switch state {
        case .idle: self = .idle
        case .recording: self = .recording
        case .transcribing: self = .processing
        case .words: self = .inserted
        case .heardNothing: self = .noSpeech
        case .failed, .micOff, .micFailed: self = .error
        }

    }
}
```

```swift
// SPDX-License-Identifier: GPL-3.0-only
// The pill's stages as images (ios/prd.json IOS-010), like desktop's ink
// shots: launched with --pill-shots (npm run ios:pill-shots), the app draws
// every stage of both styles as the keyboard shows it, writes the PNGs,
// prints where, and exits.
import UIKit

enum PillShots {
    /// Each shot: a name, and the frame drawn. Processing and inserted are
    /// caught at moments that show their motion: wet with the first sheen,
    /// dry between sheens, the softer sheen, and sinking, then flat.
    static let shots: [(name: String, frame: PillFrame)] = PillStyle.allCases.flatMap { style -> [(String, PillFrame)] in
        let moments: [(String, PillStage, TimeInterval, Bool)] = [
            ("idle", .idle, 0, false),
            ("recording", .recording, 0.5, false),
            ("recording-still", .recording, 0, true),
            ("processing-sheen", .processing, 0.3, false),
            ("processing-dry", .processing, 1.5, false),
            ("processing-again", .processing, 2.35, false),
            ("processing-still", .processing, 0, true),
            ("inserted-sinking", .inserted, 0.12, false),
            ("inserted", .inserted, 1, false),
            ("no-speech", .noSpeech, 0, false),
            ("error", .error, 0, false)
        ]
        return moments.map { name, stage, time, still in
            ("\(style.rawValue)-\(name)", PillFrame(style: style, stage: stage, levels: DemoVoice.levels, time: time, still: still))
        }
    }

    /// The pill as the keyboard shows it: the capsule on the pad's ink,
    /// with the waveform inside.
    static func image(_ frame: PillFrame, size: CGSize = CGSize(width: 236, height: 56), scale: CGFloat = 3) -> UIImage {
        let format = UIGraphicsImageRendererFormat()
        format.scale = scale
        format.opaque = true
        return UIGraphicsImageRenderer(size: size, format: format).image { renderer in
            let context = renderer.cgContext
            context.setFillColor(UIColor(Tokens.ink).cgColor)
            context.fill(CGRect(origin: .zero, size: size))
            let capsule = CGRect(origin: .zero, size: size)
            context.setFillColor(UIColor(Tokens.panelLift).cgColor)
            context.addPath(CGPath(roundedRect: capsule, cornerWidth: size.height / 2, cornerHeight: size.height / 2, transform: nil))
            context.fillPath()
            Pill.paint(frame, in: capsule.insetBy(dx: 28, dy: 14), context: context)
        }
    }

    static func runAndExit() -> Never {
        let folder = FileManager.default.temporaryDirectory.appending(path: "pill-shots", directoryHint: .isDirectory)
        try? FileManager.default.removeItem(at: folder)
        do {
            try FileManager.default.createDirectory(at: folder, withIntermediateDirectories: true)
            for shot in shots {
                guard let png = image(shot.frame).pngData() else { throw CocoaError(.fileWriteUnknown) }
                try png.write(to: folder.appending(path: "\(shot.name).png"))
            }
            FileHandle.standardOutput.write(Data("PILL_SHOTS \(folder.path)\n".utf8))
            exit(0)
        } catch {
            FileHandle.standardOutput.write(Data("PILL_SHOTS_FAILED \(error)\n".utf8))
            exit(1)
        }
    }
}
```

```js
function parsePillShotsLine(output) {
  const line = output
```

```js
async function pillShots() {

    const names = readdirSync(folder).filter((name) => name.endsWith('.png'))
```

```markdown
In murmur, tap Keyboard, then pick Bars or Speckle under The pill. Each tile is the real pill moving to a made-up voice; your microphone is never used for the tiles. The look you pick is outlined in gold, and the keyboard and the screen murmur opens to use it from your next take.

## What does the pill show on iPhone?

The pill shows where your take is, in the keyboard and on the screen murmur opens to:

- **At rest**, it is small, grey, and still. It never shows amber at rest, even while a session keeps the microphone ready.
- **Recording**, it is wet amber at your voice's level, cooling toward gold as each moment ages.
- **Working**, the paint dries to gold with one sheen, and a softer sheen every 2 seconds if it takes a while, so a long wait never looks frozen.
- **Words added**, it sinks flat.
- **Heard nothing**, it is a dry grey scrape.
- **Failed**, it is plain red. Open murmur to see why and retry.

Your iPhone gives a light tap when a take starts and when it stops. With Reduce Motion on (Settings, then Accessibility, then Motion), each stage is a still picture.
```
