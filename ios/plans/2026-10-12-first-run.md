# First Run (IOS-011) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new install reaches its first words without help. First run walks four steps in order: allow the microphone, add the murmur keyboard, turn on Full Access, and add a key. A practice take with the real pill follows, then a preview of the swipe back. Each step says why, checks itself when you come back from Settings, and can be skipped. Home lists what is left until it is done.

**Architecture:**
- `Setup` (an @Observable model) derives each step's status from the world, plus what you chose:
  - the microphone permission;
  - the keyboard's own report;
  - a saved key for today's transcription provider;
  - plus skipped steps, your word that the keyboard is added, and whether the practice take landed.
- `refresh()` reads it all again, on the way back from Settings and every second while a keyboard step waits.
- With public APIs only, an app cannot see whether its keyboard is added. So the keyboard reports itself: when it appears with Full Access, it writes `keyboard.json` to the app group, which it can only do with Full Access. That report proves both keyboard steps.
- `FirstRunScreen` shows one step and one action at a time. It opens on the first launch from the Home placeholder, which also lists what is left.
- While first run is up, a take started by the keyboard's link does not cover the screen, so practice words land in the practice box.

**Tech Stack:** Swift 6, SwiftUI (fullScreenCover(item:), sheet, scenePhase, openURL), AVAudioApplication, Swift Testing.

**Spec:** `ios/prd.json` IOS-011, with `conventions` (design, privacy, verify, docs), `CLAUDE.md`, and `DESIGN.md`. It builds on IOS-005 (the Provider and key screen), IOS-008 (the keyboard), IOS-009 (the link and the swipe guide), and IOS-010 (the pill). The design skills were consulted: frontend-design, elite-saas-designer, and ui-skills-root.

## Rulings in this plan

LaBroi can overturn any of these; each says what it costs if wrong.

1. **Public APIs only, so the keyboard reports itself.** On appearing with Full Access, the keyboard writes `keyboard.json` (a flag and a date) to the app group. That report proves both keyboard steps. Without Full Access the keyboard step takes your word ("I added it"). Two alternatives were rejected:
   - the system's AppleKeyboards default: it is written by the system, and reading it is outside UserDefaults reason CA92.1;
   - an input mode's identifier: an undocumented key, against LaBroi's 2026-08-09 public-API decision.

   If wrong: the keyboard step could check itself, at App Review risk.
2. **Open Settings goes to murmur's own page in Settings,** the closest place iOS allows. Its Keyboards row holds both the murmur switch and Allow Full Access.
3. **The keyboard steps look again every second while they show,** and every step looks again when murmur comes back to the front.
4. **A step that turns done moves on by itself after 0.9 seconds;** the practice step ends with Finish.
5. **Practice is a fifth step after the four,** so the progress reads Step 1 of 5. It is done when any words land in its box.
6. **First run opens on the first launch.** Finish later or Finish marks it seen, and the Home placeholder lists every step not done, skipped ones included, until all are done. Tapping one reopens first run at that step. IOS-012's Home will carry the same checklist.
7. **During first run, a take from the keyboard's link does not cover the screen** (`TakeOpener.quiet`), so the practice words land in the box.
8. **The key step opens the Provider and key screen as a sheet.** It is done when a key is saved for today's transcription provider; testing the key stays on that screen.
9. **The smoke's `firstRun` check walks the steps with the microphone allowed and refused,** using stand-ins for the permission, the report, and the key.
10. **The live check, a fresh install from TestFlight to first words with the time written down, waits for TestFlight 1** (IOS-015).

// SPDX-License-Identifier: GPL-3.0-only
// What the keyboard says about itself (ios/prd.json IOS-011): that it has
// appeared with Full Access, and when. A keyboard can write to the app
// group only with Full Access, so the report itself is the proof first run
// looks for; murmur reads nothing about other keyboards.
import Foundation

struct KeyboardReport: Codable, Equatable, Sendable {
    var fullAccess: Bool
    var at: Date

    static var file: URL? {
        AppGroup.containerURL?.appending(path: "keyboard.json")
    }

    static func read(from file: URL? = file) -> KeyboardReport? {
        guard let file, let data = try? Data(contentsOf: file) else { return nil }
        return try? JSONDecoder().decode(KeyboardReport.self, from: data)
    }

    func write(to file: URL? = KeyboardReport.file) {
        guard let file, let data = try? JSONEncoder().encode(self) else { return }
        try? data.write(to: file, options: [.atomic, .completeFileProtectionUntilFirstUserAuthentication])
    }
}

```swift
// SPDX-License-Identifier: GPL-3.0-only
// First run (ios/prd.json IOS-011): four steps in order, allow the
// microphone, add the murmur keyboard, turn on Full Access, and add a key,
// then a practice take. Each step's status comes from the world (the
// microphone permission, the keyboard's own report, a saved key) plus what
// you chose here (skipped, or said the keyboard is added), so a step done
// in Settings checks itself when you come back. Any step can be skipped,
// and Home lists what is left until it is done.
import AVFoundation
import Foundation
import Observation

/// The microphone permission, read and asked for.
@MainActor protocol MicrophoneAccess {
    var status: Setup.Permission { get }
    func request() async -> Bool
}

@Observable @MainActor final class Setup {
    enum Step: String, CaseIterable, Sendable {
        case microphone, keyboard, fullAccess, key, practice
    }

    enum Status: Equatable, Sendable {
        case todo, done, skipped
        /// The microphone was refused; Settings can turn it on.
        case denied
    }

    enum Permission: Sendable {
        case granted, denied, undetermined
    }

    private(set) var statuses: [Step: Status] = [:]

    @ObservationIgnored private let microphone: any MicrophoneAccess
    @ObservationIgnored private let report: @MainActor () -> KeyboardReport?
    @ObservationIgnored private let hasKey: @MainActor () -> Bool
    @ObservationIgnored private let defaults: UserDefaults

    static let seenKey = "firstRunSeen"
    static let skippedKey = "firstRunSkipped"
    static let keyboardKey = "firstRunKeyboardAdded"
    static let practicedKey = "firstRunPracticed"

    init(microphone: any MicrophoneAccess, report: @escaping @MainActor () -> KeyboardReport?, hasKey: @escaping @MainActor () -> Bool, defaults: UserDefaults = .standard) {
        self.microphone = microphone
        self.report = report
        self.hasKey = hasKey
        self.defaults = defaults
        refresh()
    }

    /// Whether first run has been shown once; after that, Home carries
    /// what is left.
    var seen: Bool {
        get { defaults.bool(forKey: Self.seenKey) }
        set { defaults.set(newValue, forKey: Self.seenKey) }
    }

    /// The steps not done yet, skipped ones included, in order.
    var remaining: [Step] {
        Step.allCases.filter { statuses[$0] != .done }
    }

    var isFinished: Bool { remaining.isEmpty }

    func status(_ step: Step) -> Status {
        statuses[step] ?? .todo
    }

    /// Checks every step again, as when you come back from Settings.
    func refresh() {
        let skipped = Set(defaults.stringArray(forKey: Self.skippedKey) ?? [])
        let fullAccess = report()?.fullAccess == true
        func open(_ step: Step) -> Status { skipped.contains(step.rawValue) ? .skipped : .todo }
        let microphone: Status = switch self.microphone.status {
        case .granted: .done
        case .denied: .denied
        case .undetermined: open(.microphone)
        }
        statuses = [
            .microphone: microphone,
            // The keyboard reports itself only with Full Access, so its report
            // proves both; without it, your word that it is added does.
            .keyboard: fullAccess || defaults.bool(forKey: Self.keyboardKey) ? .done : open(.keyboard),
            .fullAccess: fullAccess ? .done : open(.fullAccess),
            .key: hasKey() ? .done : open(.key),
            .practice: defaults.bool(forKey: Self.practicedKey) ? .done : open(.practice)
        ]
    }

    func allowMicrophone() async {
        _ = await microphone.request()
        refresh()
    }

    /// You added the keyboard; the app cannot see that until it reports.
    func keyboardAdded() {
        defaults.set(true, forKey: Self.keyboardKey)
        refresh()
    }

    func skip(_ step: Step) {
        var skipped = Set(defaults.stringArray(forKey: Self.skippedKey) ?? [])
        skipped.insert(step.rawValue)
        defaults.set(skipped.sorted(), forKey: Self.skippedKey)
        refresh()
    }

    /// Words landed in the practice box.
    func practiced() {
        defaults.set(true, forKey: Self.practicedKey)
        refresh()
    }

    /// The step to show first: the first one not done or skipped, or the
    /// first one left.
    var next: Step? {
        remaining.first { status($0) == .todo || status($0) == .denied } ?? remaining.first
    }
}

/// The device's microphone permission.
struct DeviceMicrophoneAccess: MicrophoneAccess {
    var status: Setup.Permission {
        switch AVAudioApplication.shared.recordPermission {
        case .granted: .granted
        case .denied: .denied
        default: .undetermined
        }
    }

    func request() async -> Bool {
        await AVAudioApplication.requestRecordPermission()
    }
}

extension Setup {
    private static var shared: Setup?

    /// The app's one first run: the device's microphone, the keyboard's
    /// report in the app group, and a key for today's transcription provider.
    static func live() -> Setup {
        if let shared { return shared }
        let catalog = try? BundledRules.catalog()
        let ring = KeychainKeyRing()
        let setup = Setup(
            microphone: DeviceMicrophoneAccess(),
            report: { KeyboardReport.read() },
            hasKey: {
                guard let catalog else { return false }
                let baseUrl = ConnectionStore().load(catalog: catalog).transcription.baseUrl
                return ((try? ring.key(for: baseUrl)) ?? nil) != nil
            }
        )
        shared = setup
        return setup
    }
}
```

    var status: Setup.Permission = .undetermined

                Text(SetupCopy.progress(step))
                    .font(.footnote.monospacedDigit())
                    .foregroundStyle(Tokens.textDim)
                Spacer()
                Button(SetupCopy.later) { close() }
                    .foregroundStyle(Tokens.brand)
                    .frame(minHeight: 44)
            }
            .padding(.horizontal, 24)
            StepDots(step: step, setup: setup)
                .padding(.horizontal, 24)
                .padding(.bottom, 12)
            ScrollView {
                page
                    .padding(24)
                    .frame(maxWidth: .infinity, alignment: .leading)
            }
            actions
                .padding(.horizontal, 24)
                .padding(.bottom, 16)
        }
        .background(Tokens.ink)
        .foregroundStyle(Tokens.text)
        .tint(Tokens.brand)
        .onAppear { TakeOpener.shared.quiet = true }
        .onDisappear { TakeOpener.shared.quiet = false }
        .onChange(of: scenePhase) { _, phase in
            if phase == .active { setup.refresh() }
        }
        // Waiting on the keyboard's report: look again every second.
        .task(id: step) {
            guard step == .keyboard || step == .fullAccess else { return }
            while !Task.isCancelled, setup.status(step) != .done {
                try? await Task.sleep(for: .seconds(1))
                setup.refresh()
            }
        }
        .onChange(of: setup.status(step)) { was, now in
            // Done in Settings or here: move on by itself, after a moment to
            // see the check.
            guard was != .done, now == .done, step != .practice else { return }
            Task {
                try? await Task.sleep(for: .milliseconds(900))
                advance()
            }
        }
        .onChange(of: practice) { _, text in
            if !text.isEmpty { setup.practiced() }
        }
        .sheet(isPresented: $addingKey, onDismiss: { setup.refresh() }) {
            NavigationStack { ProviderRoute() }
                .preferredColorScheme(.dark)
        }
    }

    private var page: some View {
        VStack(alignment: .leading, spacing: 20) {
            Image(systemName: Self.symbol(step))
                .font(.system(size: 34, weight: .regular))
                .foregroundStyle(Tokens.brand)
                .accessibilityHidden(true)
            Text(SetupCopy.title(step))
                .font(.largeTitle.weight(.bold))
                .accessibilityAddTraits(.isHeader)
            Text(SetupCopy.why(step))
                .font(.title3)
                .foregroundStyle(Tokens.text)
            let taps = SetupCopy.taps(step)
            if !taps.isEmpty, setup.status(step) != .done || step == .practice {
                VStack(alignment: .leading, spacing: 12) {
                    ForEach(Array(taps.enumerated()), id: \.offset) { index, tap in
                        HStack(alignment: .firstTextBaseline, spacing: 12) {
                            Text("\(index + 1)")
                                .font(.subheadline.weight(.semibold).monospacedDigit())
                                .foregroundStyle(Tokens.brand)
                                .accessibilityHidden(true)
                            Text(tap)
                        }
                        .accessibilityElement(children: .combine)
                        .accessibilityLabel("Step \(index + 1). \(tap)")
                    }
                }
            }
            if step == .fullAccess, setup.status(step) != .done {
                Box(prompt: SetupCopy.checkBox, text: $check)
            }
            if step == .practice {
                Box(prompt: SetupCopy.practiceBox, text: $practice)
                if setup.status(.practice) == .done {
                    Text(SetupCopy.practiceDone)
                        .font(.subheadline)
                        .foregroundStyle(Tokens.textDim)
                    SwipeGuide(still: reduceMotion)
                        .frame(maxWidth: .infinity)
                }
            }
            switch setup.status(step) {
            case .done:
                Note(text: SetupCopy.done, color: Tokens.ok, symbol: "checkmark.circle")
            case .denied:
                Note(text: SetupCopy.micDenied, color: Tokens.red, symbol: "mic.slash")
            case .todo, .skipped:
                EmptyView()
            }
        }
    }

    @ViewBuilder private var actions: some View {
        let status = setup.status(step)
        VStack(spacing: 4) {
            if status == .done {
                Primary(title: step == .practice ? SetupCopy.finish : SetupCopy.next) { advance() }
            } else {
                switch step {
                case .microphone where status == .denied, .keyboard, .fullAccess:
                    Primary(title: SetupCopy.openSettings) { openSettings() }
                case .microphone:
                    Primary(title: SetupCopy.allow) { Task { await setup.allowMicrophone() } }
                case .key:
                    Primary(title: SetupCopy.addKey) { addingKey = true }
                case .practice:
                    EmptyView()
                }
                if step == .keyboard {
                    Secondary(title: SetupCopy.added) { setup.keyboardAdded() }
                }
                Secondary(title: SetupCopy.skip) {
                    setup.skip(step)
                    advance()
                }
            }
        }
    }

    private func openSettings() {
        if let url = URL(string: UIApplication.openSettingsURLString) { openURL(url) }
    }

    /// The next step in order, or the end.
    private func advance() {
        let all = Setup.Step.allCases
        guard let index = all.firstIndex(of: step), index + 1 < all.count else { return close() }
        step = all[index + 1]
    }

    private func close() {
        setup.seen = true
        dismiss()
    }

    static func symbol(_ step: Setup.Step) -> String {
        switch step {
        case .microphone: "mic"
        case .keyboard: "keyboard"
        case .fullAccess: "lock.open"
        case .key: "key"
        case .practice: "waveform"
        }
    }

    /// First run walks its steps with the microphone allowed and refused
    /// (IOS-011): allowed, every step checks itself done in turn; refused,
    /// the microphone says so and waits on Home while the rest go on.
    static func checkFirstRun() throws {
        if let failure = onMain({ await firstRunFailure() }) { throw SmokeFailure(failure) }
    }

    @MainActor private static func firstRunFailure() async -> String? {
        for allowed in [true, false] {
            guard let defaults = UserDefaults(suiteName: "murmur.smoke.\(UUID().uuidString)") else { return "no scratch defaults" }
            let report = Cell<KeyboardReport?>(nil)
            let key = Cell(false)
            let setup = Setup(microphone: ScriptedAccess(answer: allowed), report: { report.value }, hasKey: { key.value }, defaults: defaults)
            guard setup.next == .microphone else { return "first run did not start with the microphone" }
            await setup.allowMicrophone()
            guard setup.status(.microphone) == (allowed ? .done : .denied) else { return "the microphone read \(setup.status(.microphone)) when allowed was \(allowed)" }
            setup.keyboardAdded()
            report.value = KeyboardReport(fullAccess: true, at: .now)
            key.value = true
            setup.refresh()
            setup.practiced()
            let left: [Setup.Step] = allowed ? [] : [.microphone]
            guard setup.remaining == left else { return "left \(setup.remaining) when allowed was \(allowed)" }
        }
        return nil
    }
