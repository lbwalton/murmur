# murmur Pro on iPhone (IOS-025) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-time purchase that supports murmur, sold the way Apple requires, and never in the way of the free app. murmur Pro is a StoreKit 2 non-consumable at a price LaBroi sets; it carries desktop's promise (provider profiles, early access, the supporter mark), restores on a new phone, ends on a refund, and a purchase made with a founders offer code shows Founding member. A desktop license key never unlocks anything on iPhone.

**Architecture:**
- **Pro's rules** are a small pure function over the App Store's record of purchases: the earliest purchase not refunded is Supporter since, and one made with the `founders` offer code is a founding member's.
- **ProStore** follows the App Store through a `ProShop`: the real one is StoreKit 2 (price, purchase, `AppStore.sync` for Restore purchases, `Transaction.updates` from launch); the smoke's is a stand-in played out from the same StoreKit configuration file the tests run on, since StoreKit's test session links only into test bundles.
- **The StoreKit configuration** `ios/murmur.storekit` (text) holds the product and the founders code. The app's tests run real StoreKit on it (buy, a code offer, a refund, restore); the smoke reads it from the Mac.
- **Settings, murmur Pro** shows what Pro adds, the App Store's price, Get murmur Pro, Redeem a code (StoreKit's sheet), and Restore purchases; once bought, the supporter mark and the date. Settings gains a murmur Pro row after what you use, with the mark in gold once bought.
- **Provider profiles** save the whole provider setup (transcription and cleanup) under a name and switch in one tap, as desktop's do; keys stay in the key ring. Only Pro saves, switches, or deletes them; without Pro they wait, untouched.

**Tech Stack:** Swift 6, Swift Testing, SwiftUI, StoreKit 2, StoreKitTest (test bundle only), Node (the smoke's launch argument).

**Spec:**
- `ios/prd.json` IOS-025 and its `decisions` and `conventions` (design, privacy, docs, verify).
- Desktop's Pro, murmur's own: `docs/pro.md` (the promise), `src/main/profiles.ts` (profiles keep addresses and models, never keys, and need Pro), `src/renderer/settings/App.tsx` ProSection (Pro is active or Founding member, Supporter since, belts stay earned).
- `CLAUDE.md` (gold for labels and iPhone action rows, red only for errors, no paint on these screens, lowercase murmur, no em dashes) and `DESIGN.md`.

The design skills were consulted (frontend-design, elite-saas-designer, ui-skills-root): the screen leads with what stays free, lists what Pro adds under its own heading, keeps every action a gold row of at least 44 points, and shows red only for a purchase or restore that failed.

## Rulings in this plan

LaBroi can overturn any of these; each says what it costs if wrong.

1. **The product id is the bundle id with `.pro`** (`com.lbwalton.murmur.ios.pro`), read from Info.plist so a self-built copy names its own. If wrong: one line in project.yml and one in App Store Connect.
2. **A founding member is a purchase made with an offer code whose reference name is `founders`** (any case), read from the transaction's offer. LaBroi names the offer exactly that in App Store Connect. If wrong: one constant.
3. **The smoke drives Pro through a stand-in made from `ios/murmur.storekit`,** passed as `--storekit=<path>` and read from the Mac; StoreKit's own test session runs in the tests. StoreKitTest has no runtime in the simulator outside a test bundle (checked 2026-10-15). If wrong: none; the tests run real StoreKit.
4. **Pro listens to the App Store from launch** (`Transaction.updates`), so a purchase on another phone, a code redeemed in the App Store, or a refund lands without opening the screen.
5. **Profiles hold the whole setup, transcription and cleanup,** where desktop's hold one provider block; iPhone's settings are those two blocks. Keys stay in the key ring.
6. **Without Pro, saved profiles stay saved and untouched** but cannot be used, as desktop's gate; buying Pro again brings them back.
7. **Early access has nothing to hold yet on iPhone;** the screen and the docs state the promise, and `ProStatus` is there for the first Pro-first convenience.
8. **The murmur Pro row sits after Notes in Settings, never first,** so the free app is never led by a sale; its mark is gold once bought.
9. **No Apple account or price work is done from here.** Creating the in-app purchase, its price, the founders offer, and sandbox codes in App Store Connect are LaBroi's steps in HANDOFF.md.

```swift
// SPDX-License-Identifier: GPL-3.0-only
// What murmur Pro is on iPhone (ios/prd.json IOS-025): a one-time Apple
// in-app purchase, never a license key (App Review 3.1.1). Pro comes from
// the App Store's own record of what you bought: the earliest purchase not
// refunded is when you became a supporter, and a purchase made with one of
// the founders' offer codes is a founding member's. Belts and cosmetics are
// never for sale; Pro unlocks conveniences only.
import Foundation

/// One purchase of murmur Pro, as the App Store records it.
struct ProPurchase: Equatable, Sendable {
    let product: String
    let purchased: Date
    /// When it was refunded, or nil.
    let revoked: Date?
    /// The reference name of the offer code it was bought with, or nil.
    let code: String?
}

enum ProStatus: Equatable, Sendable {
    case free
    /// since is when the earliest purchase still in force was made.
    case pro(since: Date, founder: Bool)

    var isPro: Bool {
        if case .pro = self { true } else { false }
    }

    var isFounder: Bool {
        if case .pro(_, true) = self { true } else { false }
    }
}

enum ProRules {
    /// The offer code reference name LaBroi gives the founders' one-time
    /// codes in App Store Connect.
    static let foundersCode = "founders"

    /// Pro's product id: the app's bundle id with .pro, from Info.plist,
    /// so a self-built copy names its own product.
    static var productId: String {
        Bundle.main.object(forInfoDictionaryKey: "MurmurProProduct") as? String ?? "com.lbwalton.murmur.ios.pro"
    }

    /// Pro from the purchases: free with none in force, a founding member
    /// when any purchase in force used a founders code.
    static func status(_ purchases: [ProPurchase], product: String) -> ProStatus {
        let held = purchases.filter { $0.product == product && $0.revoked == nil }
        guard let first = held.map(\.purchased).min() else { return .free }
        let founder = held.contains { $0.code?.caseInsensitiveCompare(foundersCode) == .orderedSame }
        return .pro(since: first, founder: founder)
    }
}
```

```swift
        let type: String
```

```swift
        #expect(phone.status.isPro)
        #expect(phone.message == nil)

        #expect(store.status.isFounder)

        await store.buy()
        #expect(store.status == .free)
        #expect(store.message == message)
        #expect(store.busy == nil)

        let store = ProStore(shop: ScriptedShop(file), product: product)
        await store.restore()
        #expect(store.message == ProCopy.nothingToRestore)

        await offline.restore()

/// The real StoreKit, in Xcode's test environment, on ios/murmur.storekit.
/// One session plays the whole story in order, since every test shares the
/// one StoreKit test environment, and each step waits for StoreKit to
/// settle: a purchase, a refund, a founders code, and a restore.
@MainActor @Suite(.serialized) struct ProStoreKitTests {
    let product = ProRules.productId

    /// Refreshes until the store says so, or five seconds pass.
    func settle(_ store: ProStore, until done: @MainActor () -> Bool) async throws {
        for _ in 0..<50 where !done() {
            try await Task.sleep(for: .milliseconds(100))
            await store.refresh()
        }
    }

    @Test func aPurchaseARefundAFoundersCodeAndARestore() async throws {
        let session = try SKTestSession(contentsOf: storeKitFileURL)
        session.resetToDefaultState()
        session.clearTransactions()
        session.disableDialogs = true
        let store = ProStore(shop: StoreKitShop(), product: product)
        await store.start()
        try await settle(store) { store.status == .free }
        #expect(store.status == .free)
        #expect(store.price == "$39.99")

        let bought = try await session.buyProduct(identifier: product)
        try await settle(store) { store.status.isPro }
        #expect(store.status.isPro)
        #expect(!store.status.isFounder)

        try session.refundTransaction(identifier: UInt(bought.id))
        try await settle(store) { store.status == .free }
        #expect(store.status == .free)

        let coded = try await session.buyProduct(identifier: product, options: [.codeOffer(referenceName: ProRules.foundersCode)])
        #expect(StoreKitShop.purchase(coded).code == ProRules.foundersCode)
        try await settle(store) { store.status.isFounder }
        #expect(store.status.isFounder)

        await store.restore()
        #expect(store.status.isFounder)
        #expect(store.message == nil)
    }
}
```

```swift
// SPDX-License-Identifier: GPL-3.0-only
// murmur Pro's purchase on iPhone (ios/prd.json IOS-025), through StoreKit
// 2: the price, buying, Restore Purchases, and the App Store's updates
// (a purchase on another phone, a code redeemed in the App Store, a
// refund). Nothing in the free app ever waits on it: Pro starts free and
// becomes Pro only once the App Store says so.
import Foundation
import Observation
import StoreKit

/// How a purchase ended.
enum ProBuy: Equatable, Sendable {
    case bought, cancelled, pending, failed
}

/// The App Store as Pro sees it, so the smoke can stand one in.
protocol ProShop: Sendable {
    /// The price to show, or nil when Pro cannot be bought right now.
    func price(_ product: String) async -> String?
    /// The purchases of the product the App Store knows on this phone.
    func purchases(_ product: String) async -> [ProPurchase]
    func buy(_ product: String) async -> ProBuy
    /// Restore Purchases: asks the App Store for this Apple Account's.
    func restore() async -> Bool
    /// Each change the App Store sends while murmur runs.
    func updates() -> AsyncStream<Void>
}

@Observable @MainActor final class ProStore {
    enum Busy: Equatable {
        case buying, restoring
    }

    private(set) var status: ProStatus = .free
    /// Nil until the App Store answers, or when Pro is not for sale now.
    private(set) var price: String?
    private(set) var busy: Busy?
    /// What the last buy or restore came to, for the screen to say.
    private(set) var message: String?

    @ObservationIgnored let product: String
    @ObservationIgnored private let shop: any ProShop
    @ObservationIgnored private var listening: Task<Void, Never>?

    init(shop: any ProShop, product: String = ProRules.productId) {
        self.shop = shop
        self.product = product
    }

    /// Reads the price and what was bought, then follows the App Store's
    /// updates for as long as the store lives.
    func start() async {
        if listening == nil {
            let updates = shop.updates()
            listening = Task { [weak self] in
                for await _ in updates { await self?.refresh() }
            }
        }
        price = await shop.price(product)
        await refresh()
    }

    func refresh() async {
        status = ProRules.status(await shop.purchases(product), product: product)
    }

    func buy() async {
        guard busy == nil else { return }
        busy = .buying
        message = nil
        defer { busy = nil }
        switch await shop.buy(product) {
        case .bought: await refresh()
        case .cancelled: break
        case .pending: message = ProCopy.pending
        case .failed: message = ProCopy.buyFailed
        }
    }

    func restore() async {
        guard busy == nil else { return }
        busy = .restoring
        message = nil
        defer { busy = nil }
        let synced = await shop.restore()
        await refresh()
        if !synced { message = ProCopy.restoreFailed } else if !status.isPro { message = ProCopy.nothingToRestore }
    }

    private static var shared: ProStore?

    /// The app's one Pro store, on the real App Store.
    static func live() -> ProStore {
        if let shared { return shared }
        let store = ProStore(shop: StoreKitShop())
        shared = store
        return store
    }
}

/// The real App Store, through StoreKit 2.
struct StoreKitShop: ProShop {
    func price(_ product: String) async -> String? {
        (try? await Product.products(for: [product]))?.first?.displayPrice
    }

    func purchases(_ product: String) async -> [ProPurchase] {
        var found: [ProPurchase] = []
        for await result in Transaction.currentEntitlements(for: product) {
            guard case .verified(let transaction) = result else { continue }
            found.append(Self.purchase(transaction))
        }
        return found
    }

    func buy(_ product: String) async -> ProBuy {
        guard let item = try? await Product.products(for: [product]).first else { return .failed }
        do {
            switch try await item.purchase() {
            case .success(.verified(let transaction)):
                await transaction.finish()
                return .bought
            case .success(.unverified):
                return .failed
            case .userCancelled:
                return .cancelled
            case .pending:
                return .pending
            @unknown default:
                return .failed
            }
        } catch {
            return .failed
        }
    }

    func restore() async -> Bool {
        (try? await AppStore.sync()) != nil
    }

    func updates() -> AsyncStream<Void> {
        AsyncStream { continuation in
            let task = Task.detached {
                for await result in Transaction.updates {
                    if case .verified(let transaction) = result { await transaction.finish() }
                    continuation.yield()
                }
            }
            continuation.onTermination = { _ in task.cancel() }
        }
    }

    static func purchase(_ transaction: Transaction) -> ProPurchase {
        let code = transaction.offer.flatMap { $0.type == .code ? $0.id : nil }
        return ProPurchase(product: transaction.productID, purchased: transaction.purchaseDate, revoked: transaction.revocationDate, code: code)
    }
}
```

```swift
// SPDX-License-Identifier: GPL-3.0-only
// The App Store as the smoke plays it (ios/prd.json IOS-025): products and
// offer codes read from ios/murmur.storekit, the StoreKit configuration the
// app's tests run on, and purchases, refunds, and codes played out in
// memory. StoreKit's own test session runs only inside a test bundle, so
// the smoke drives murmur Pro through this stand-in made from the same file.
import Foundation
import Synchronization

final class ScriptedShop: ProShop {
    private let file: StoreKitFile
    private let state = Mutex<(bought: [ProPurchase], waiting: [AsyncStream<Void>.Continuation])>(([], []))

    init(_ file: StoreKitFile, bought: [ProPurchase] = []) {
        self.file = file
        state.withLock { $0.bought = bought }
    }

    var bought: [ProPurchase] { state.withLock { $0.bought } }

    func price(_ product: String) async -> String? {
        file.products.first { $0.productID == product }.map { "$" + $0.displayPrice }
    }

    func purchases(_ product: String) async -> [ProPurchase] {
        state.withLock { $0.bought.filter { $0.product == product && $0.revoked == nil } }
    }

    func buy(_ product: String) async -> ProBuy {
        buy(product, code: nil) ? .bought : .failed
    }

    /// A purchase, with the offer code it was redeemed with; false for a
    /// product or code the file does not have.
    @discardableResult
    func buy(_ product: String, code: String?) -> Bool {
        guard let item = file.products.first(where: { $0.productID == product }) else { return false }
        if let code, !(item.offerCodes ?? []).contains(where: { $0.referenceName == code }) { return false }
        state.withLock { $0.bought.append(ProPurchase(product: product, purchased: .now, revoked: nil, code: code)) }
        announce()
        return true
    }

    func restore() async -> Bool { true }

    /// Apple refunds every purchase of the product.
    func refund(_ product: String) {
        state.withLock { state in
            state.bought = state.bought.map { $0.product == product ? ProPurchase(product: $0.product, purchased: $0.purchased, revoked: .now, code: $0.code) : $0 }
        }
        announce()
    }

    func updates() -> AsyncStream<Void> {
        AsyncStream { continuation in state.withLock { $0.waiting.append(continuation) } }
    }

    private func announce() {
        for continuation in state.withLock({ $0.waiting }) { continuation.yield() }
    }
}
```

```swift
// Provider profiles (murmur Pro, ios/prd.json IOS-025), as on desktop
// (src/main/profiles.ts): save the whole provider setup, transcription and
// cleanup, under a name, and switch between setups in one tap. Profiles
// hold addresses and model ids only; the key ring supplies each address's
// key, so a profile never carries a key. The free single setup is
// untouched: profiles are kept when Pro ends, and come back with it.
import Foundation
import MurmurCore

struct ProviderProfile: Codable, Equatable, Identifiable, Sendable {
    let id: String
    let name: String
    let settings: ConnectionSettings

    /// Names are trimmed and kept to 40 characters, as desktop's.
    static let nameLimit = 40

    /// A profile of these settings under this name, or nil for a blank name.
    static func make(_ name: String, settings: ConnectionSettings, id: String = String(UUID().uuidString.lowercased().prefix(8))) -> ProviderProfile? {
        let trimmed = name.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else { return nil }
        return ProviderProfile(id: id, name: String(trimmed.prefix(nameLimit)), settings: settings)
    }
}

    static let profilesKey = "providerProfiles"

    /// The saved profiles, or none when they no longer read.
    func profiles() -> [ProviderProfile] {
        guard let data = defaults.data(forKey: Self.profilesKey),
              let saved = try? JSONDecoder().decode([ProviderProfile].self, from: data)
        else { return [] }
        return saved
    }

    func saveProfiles(_ profiles: [ProviderProfile]) {
        defaults.set(try? JSONEncoder().encode(profiles), forKey: Self.profilesKey)
    }
}
```

```markdown
Open murmur, tap the gear, then murmur Pro, and tap Get murmur Pro. It is a one-time purchase through the App Store with your Apple Account, and it supports murmur. Everything you use today stays free: dictation, cleanup, notes, the Journey, and every provider. Pro adds:
```
